🏗 Architecture microservices

Découpage en 11 services indépendants (Docker Compose), chacun avec son propre Dockerfile, ses dépendances, et sa propre limite mémoire. Aucun ne partage d'état ni de code Python avec un autre.

Règle absolue du projet : zéro import Python direct entre services. Toute communication passe par HTTP — /health, /v1/..., /api/v1/.... Ça permet à chaque service d'évoluer, de crasher ou de redémarrer sans emporter les autres avec lui.
Inférence
backend :8000
FastAPI — classification COVID/Normal/Lung Opacity/Viral Pneumonia. Preprocessing identique à l'entraînement (réutilise le code du trainer, copié au build).
segmentation-service :8001
FastAPI — U-Net, isole le masque pulmonaire avant classification. Appelé en HTTP par backend.
Données & pipeline ML
data-service :5001
Lecture seule — stats et recherche sur le jeu de données (42 330 images versionnées DVC).
dvc-service :5003
Opérations DVC (status/pull/push/repro), séparé de data-service (lecture vs mutation d'état).
trainer :8888
Pipeline d'entraînement reproductible (dvc repro) — preprocess → train → evaluate, orchestré par dvc.yaml/params.yaml.
Tracking & stockage
mlflow :5000
Tracking server + Model Registry. backend/segmentation-service chargent leur modèle depuis le stage Production, fallback fichier local si indisponible.
postgres interne
Backend de métadonnées MLflow (runs, métriques, paramètres).
minio :9000 / :9001
Stockage S3 local — artefacts MLflow (modèles) et remote DVC (dataset).
DagsHub externe
Miroir du repo — suivi natif des expériences DVC (commits, métriques par run), complémentaire à MLflow.

Accès direct aux outils de tracking (MLflow local, DagsHub) : voir l'onglet Expériences.

Observabilité
log-service :5002
Agrégateur JSON centralisé — reçoit les logs structurés de tous les autres services.
prometheus :9090
Scrape /metrics du backend (latence, volumétrie de prédictions). Profil monitoring.
grafana :3000
Dashboards provisionnés sur les métriques Prometheus. Profil monitoring.
Interfaces
streamlit :8501
Frontend Streamlit multi-pages — exploration data science.
dashboard :5050
Backlog agile + data explorer (outil interne équipe).
demonstration :5051
Cette présentation — façade démo produit, appelle backend directement.

Pipeline d'entraînement

Pipeline DVC reproductible (dvc repro, figé par dvc.lock) — détail complet (stages, architecture des modèles, preprocessing) sur l'onglet Pipeline (DVC & Models). Voir aussi Monitoring pour le suivi post-déploiement.
