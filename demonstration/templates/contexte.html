🫁 D'où part le projet — contexte Data Science

Ce projet MLOps industrialise un pipeline construit lors d'une phase Data Science antérieure (repo DS_COVID, équipe Cirine B., Lena B., Steven M., Rafael C.). Page condensée à titre de contexte — le travail jugé à cette soutenance est l'industrialisation (voir le backlog), pas cette phase exploratoire.

Les tests RT-PCR sont lents et de sensibilité variable. L'imagerie médicale (radiographie thoracique) permet un triage plus rapide — mais les patterns radiologiques du COVID-19 sont proches d'autres pneumonies, et les radiologues sont en surcharge. D'où l'objectif : une classification automatique interprétable, en appui au diagnostic.

Objectif SMART initial

SClassification COVID vs non-COVID MF1 ≥ 0,80 sur validation indépendante AFine-tuning d'InceptionV3 (transfer learning) RRéduire les faux négatifs TDémonstration au 12/01/2024

Résultat baseline — Machine Learning classique

Modèles testés sur un échantillon équilibré (200 images/classe), évalués par matrice de confusion :

  • Support Vector Machine (SVM)
  • k-Nearest Neighbors (k-NN)
  • Random Forest

✅ Random Forest : modèle le plus performant. ❌ SVM : le moins performant. Optimisation par Grid Search (validation croisée) sur les deux.

Résultat baseline — Deep Learning (modèle retenu)

InceptionV3 (transfer learning), entraîné sur 2 000 images : 20 epochs de feature extraction puis 30 epochs de fine-tuning (20 dernières couches dégelées).

Performance globale jugée très bonne, bonne identification des 3 classes (COVID, pneumonie virale, normal). Le transfert d'apprentissage InceptionV3 est efficace sur ce type d'images médicales.

Interprétabilité : LIME (Local Interpretable Model-Agnostic Explanations) — méthode compréhensible, fiable et généralisable, utilisée pour visualiser les zones de l'image ayant motivé chaque prédiction.

À partir de ce modèle exploratoire, l'industrialisation MLOps (Phases 1→4) a mis en place : une API de service, des microservices, du versioning de données/modèles (DVC, MLflow), du CI/CD, un déploiement Kubernetes, et du monitoring.
